# 卡待删架构合同

与[产品需求](产品需求.md)共同构成唯一现役合同，冲突以需求为准。重建范围以当前实现及用户已确认改造为依据，不恢复工作区删除的历史文件。

## 工程与职责

`kadaishan/` 为 Kotlin + Jetpack Compose Material3 单 Activity 工程，包名 dev.sxc.kadaishan；JDK 17、SDK 35。构建入口、镜像与安装见 [AGENTS](../AGENTS.md#构建与安装)。无新增数据库、识别模型、后台索引服务或网络权限。

媒体访问收敛 `MediaSource` / `MediaStoreDataSource`；MediaStore 决定当前权限可见范围。分类复用 `classifyFields` 的路径/目录名/文件名规则；日期只参与排序和时间片段，不更改分类判据。

`SessionController` 创建 ID 快照；`BoardSession` 管理轮次、指针、标记和撤回。`ReviewHistory` 独立 DataStore 保存明确保留记录，必须写入成功后再应用动作；未结算标记只在内存。`PhotoCardViewModel` 和 `VideoCardViewModel` 提供屏幕状态，详情按需加载和预取，UI 采用 DesignKit/Daylight 公共组件。

## 智能混排接入

规则与验收以[专题方案](图片智能混排方案.md)为唯一详细定义。新增轻量 SelectionRow 查询、纯 Kotlin SmartOrder 与 SortSpec.Smart。普通排序仍走旧 ids；图片 Smart 走元数据扫描、保留过滤和后台调度；视频 Smart 映射旧 Random，不调用图片扫描接口。

扫描 IO、计算 Default，均支持取消；构建成功再安装 ID 会话，不保留元数据常驻队列。主线程安装新会话后、refresh/ready 前，无挂起重放最新轮次张数。初次加载与重试共用入口，重建单飞，不让旧任务覆盖新状态。图片加载失败区分权限和读取故障，提供重试，禁止把异常当空相册。

设置仍使用 sort_strategy，共享图片/视频；SMART 编码新增，原值与随机回退不变。分组不落盘，不增加冷却/公平历史；退出后不保证续接。BoardSession 核心动作和删除状态机不因排序改造。

## 删除、恢复与游戏隔离

删除仅走 createTrashRequest(true)/createDeleteRequest，恢复仅走 createTrashRequest(false)。切批前 queryByIds 验活；MATCH_INCLUDE 回查三态才是最终事实，包括系统拒绝路径。批量上限见需求合同。PendingSettlement 由独立 DataStore 维护，不与排序/游戏文件混用。

AppContainer 按进程单例组装共享依赖。修仙引擎纯 Kotlin，存档、工具奖励轮次与设置/媒体状态隔离；存档兼容、前后台一致性和未完成验证见[修仙开发说明](掌中修仙开发说明.md)。排序不更改有效轮次奖励条件。

## 验证边界

统一 assembleDebug test 门禁；纯算法做集合、顺序、时间边界和取消测试，接入做假源与异步轮数测试。真机媒体权限、性能、删除/恢复与网络行为单独取证，未完成时明确保留待验收状态。
