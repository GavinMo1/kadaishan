# 掌中修仙开发说明

玩法口径见根目录《照片清理App_放置养成玩法设计方案》。本文件只记录实现职责与验证入口。

## 代码入口

- `domain/cultivation/CultivationEngine.kt`：纯 Kotlin 确定性战斗、离线结算、掉落/保底、装备、强化、突破和转世。
- `data/CultivationRepository.kt`：独立 Preferences DataStore，JSON schema 校验；串行更新，每个离线结算块原子保存，错误不重置原存档。
- `data/CultivationRoundBridge.kt`：工具侧独立序号存储，开始轮次时分配；完成事件异步送游戏，不携带媒体 URI、不等待奖励。
- `ui/cultivation/CultivationScreen.kt`：历练、装备、历世与转世预览，前台按生命周期刷新；不运行后台任务。
- `AppContainer.get`：进程内共享组装根，避免页面重建产生多个游戏写入者。

游戏文件与 settings、PendingSettlement 分离；隐藏不暂停，显式暂停才停止收益；重置只覆盖游戏文件。工具轮次序号存储不随游戏重置清除。
